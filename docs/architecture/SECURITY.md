# Security & data handling
Threats: cross-tenant read (guessed document URL, phone lookup) · account takeover via recycled phone · forwarded QR · replayed provider webhook · duplicate credit pull on retry · executed-document mutation · secrets in repo · prompt injection via buyer messages into AI · payment-destination change fraud.
Controls: server-enforced authz on every sensitive read/write; RLS + storage policies tested with DOA tests; least-privilege dealer membership and roles; MFA for dealer staff; encrypted storage; access audit events; retention limits; controlled upload links; idempotency keys; webhook signature verification; payment-destination change requires out-of-band confirmation; AI output validated by claims registry; consent records for every automated message; secrets only in environment variables (cloud environment settings), never files.
Programs: GLBA Safeguards WISP; SOC 2 Type 1 target before real NPI at scale; TDPSA notice/DPA/consent; TRAIGA AI disclosure; TCPA consent/revocation; incident response plan; published wind-down policy (dealer non-payment never paywalls buyer records).
