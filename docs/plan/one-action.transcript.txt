[  0.0-  3.3] If you're designing an app, stop giving users so many choices.
[  3.3-  7.1] Spotify wants you to press play, Netflix wants you to start the next episode, and Tinder
[  7.1-  8.4] wants you to keep swiping.
[  8.4- 12.2] This is called Hicks Law, which says that the more choices you give someone, the longer
[ 12.2- 13.4] they take to decide.
[ 13.4- 15.5] And that friction is what kills retention.
[ 15.5- 16.5] So here are five rules.
[ 16.5- 17.5] 1.
[ 17.5- 19.4] Give every screen one obvious primary action.
[ 19.4- 20.4] 2.
[ 20.4- 23.1] Your main button should look more important than everything else around it.
[ 23.1- 24.1] 3.
[ 24.1- 26.1] Hide advanced options until someone actually needs them.
[ 26.1- 27.1] 4.
[ 27.1- 29.0] Never have two buttons that look equally important.
[ 29.0- 30.0] 5.
[ 30.0- 31.4] If an option isn't relevant yet, don't show it.
