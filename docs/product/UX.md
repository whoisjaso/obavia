# UX
Standards live in `.claude/skills/obavia-ux-standards/SKILL.md`. This file holds the concrete journeys.

## Buyer journey (first slice candidates)
Browse without account → save/inquire (light account) → see dealer reply in the same thread → "Check in at this dealership" (short-lived QR/code) → authorize continuation → see deal status as separate facts: paperwork · payment · delivery · registration → documents vault → review invitation.
Buyer status example: "Paperwork signed. Vehicle delivered. Registration in progress."

## Dealer journey
Today mode (five things that need you) → open the exact customer case → Start/Continue deal (prefilled, reviewed) → guided packet or completed-packet review → signing (electronic / printed / mixed, tracked separately) → record delivery with evidence → registration task list → feedback prompt.
Dealer status example: "Delivery recorded. Funding reconciliation needs attention. Registration packet ready."

## Walk-in
Minimal dealer-local prospect + secure invitation. Typing a name creates no public account and no consent.

## Screens to spec per slice
Listing card · inquiry thread · dealer inbox (grouped by vehicle, with stage/next action/owner) · customer card · deal workspace · document list with per-document signing method and status · buyer status page · registration tracker · review prompt.
