# Marketing experiments (one at a time, next to the active slice)
Format: hypothesis · audience · offer · observable outcome · stop condition · decision owner · claims used (must be in CLAIMS_REGISTRY).

## EXP-01 Founding dealer application page (M0)
Hypothesis: Houston independent dealers (10–80 units/mo) will apply for a founding cohort when the message is "you are the whole dealership; Obavia keeps the deal moving." Audience: Meta lookalike from Triple J + TIADA lists; EN and ES as separate experiments. Offer: apply → 20-min interview → founding pilot (Apohenia packet check now; workspace when ready). Outcome: ≥10 interviews, ≥5 dealers willing to run one real transaction. Stop: <2 interviews per $300 spend across two creatives. Owner: Jason. Collect: dealership, location, inventory size, current systems, primary pain, monthly transactions, language. Never collect credit/ID data.
