# Obavia app

The owner and rep workspace. Vite + React + TypeScript, deployed on its own, separate from the marketing site in `../obavia-co`.

```bash
npm install
npm run dev      # local
npm run build    # outputs dist/
```

Cloudflare Pages, second project: root directory `app`, build command `npm run build`, output directory `dist`, custom domain `app.obavia.co`.
